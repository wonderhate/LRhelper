# 0.6 局部蒙版与肤色保护

1. 在 Lightroom 选中一张照片并读取。在工作台勾选「局部蒙版与肤色保护」，再生成方案、适配单张风格或继续调整。可直接描述区域和目标，例如「只压低天空高光，保留全局设置」。
2. 在「参数差异」查看各蒙版的区域、滑块值与理由，以及本轮肤色保护。Lightroom 在预览时识别区域。若画面没有清晰的主体或天空，方案可以只包含全局调整。
3. 点击「预览副本」查看 Lightroom 渲染的前后图。每轮在新虚拟副本上创建快照，再写入并读回。点击「恢复副本」应用快照，右图保留上次预览供比较。

局部滑块包括曝光、高光、阴影和饱和度，每个区域最多一份 Studio 新建蒙版。主体覆盖 Lightroom 检测到的整个主体。肤色保护使用目标画面的视觉判断，对可见或不确定的肤色限制本轮全局红色与橙色的色相、饱和度和明亮度变化。

新会话默认关闭该选项。继续调整时会继承同一会话的累计蒙版。勾选后可以更改这些局部参数，例如「撤掉天空高光调整」，100% 强度可把该滑块归零。批量适配和固定 XMP 继续使用全局参数。适配已保存风格时，可勾选该选项让 Codex 依据新照片重新提议蒙版。

若 Lightroom 没有找到区域并弹出检测提示，请在 Lightroom 点「确定」。工作台会尝试恢复快照。如果显示自动恢复失败，关闭 Lightroom 的检测提示后，点「恢复副本」。

预览前会重新核对源照片的显影设置与渲染。若源照片已有调整发生变化，请重新读取并生成方案。

命令行的 `plan`、`refine` 和 `apply-style` 支持 `--local-masks`。

```powershell
./scripts/studio.ps1 plan --mode describe --prompt '只压低天空高光' --local-masks
./scripts/studio.ps1 preview JOB_ID
./scripts/studio.ps1 restore JOB_ID
```
