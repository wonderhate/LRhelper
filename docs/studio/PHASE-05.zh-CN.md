# 0.5 批量风格适配

1. 在 Lightroom 选中 2–8 张照片。在工作台的「批量」选择已保存的风格，用上方「风格强度」设置本批强度，点击「为所选照片生成」。点击时的照片选择会固定为该批次的范围。
2. 生成阶段逐张读取 Lightroom 渲染图和现有参数。选择一张批次照片并点击「查看此张」，在「分析与适配」和「参数差异」查看结果。还可以点击「停止生成」，保留已完成的方案。
3. 点击「预览副本」可只预览当前打开的照片。点击「预览本批方案」会依次预览批次内所有仍可用的方案。每张照片分别创建虚拟副本和快照。回到批次选择照片并点击「查看此张」，可以比较前后图或点击「恢复副本」。

关闭后可以从「历史批次」打开最近 30 个批次。改选批次后需点击「打开批次」，整批预览才会按打开后的批次启用。「预览副本」和「恢复副本」始终对应上方对比区的照片。

每批的照片、方案和副本状态保存在本地。生成失败和无参数变化的照片会分别标记。预览前若源照片已经改动，该方案会被跳过。若副本创建结果不确定或自动恢复失败，整批预览会停止。此时用批次照片列表找到对应照片，检查 Lightroom 中的副本与快照，再决定如何恢复。重新启动后仍可查看记录和已完成方案。

批次记录位于 `.studio/batches/`，每张照片的任务和渲染位于 `.studio/jobs/`。也可以离线查看批次记录。

```powershell
./scripts/studio.ps1 batches
./scripts/studio.ps1 batch-show BATCH_ID
```

升级时关闭工作台并重启 Studio Host，再在 Lightroom 增效工具管理器中重新载入 LR Codex Studio。
