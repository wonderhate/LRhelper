# 0.3：多轮调色与风格库

本阶段延续 Lightroom 原生 LrView 工作台。用户选择保存调色意图和参考图副本，并在新照片上重新适配。实现范围包括多轮反馈、历史轮次、会话恢复、新会话、本地风格保存及风格适配；XMP、批量和局部蒙版仍为后续阶段。

## 多轮调色

在第一轮完成“预览副本”后，进入“对话”，填写调整意见并点击“继续调整”。模型读取上一轮真实 Lightroom 渲染、累计参数及当前分支的对话历史，只返回本轮需要改变的参数。Host 保留未提及的上一轮参数。

新方案仍需点击“预览副本”执行。每轮创建独立虚拟副本和基线快照；恢复某一轮只恢复该轮副本。比较图以本会话初始照片为基准；参数页同时显示本轮差异与累计差异。外部修改源照片后，需要重新读取并开始新会话。

顶部会话列表可打开历史会话；“对话”中的轮次列表可查看早期结果，并从已渲染轮次分支。“新会话”清空当前工作上下文，保留历史记录和所有副本。当前上限为每条分支 20 轮，会话列表显示最近 200 个会话。

项目会话从私有任务链恢复。每轮使用新建的隔离 SDK 线程，将所选分支的历史和最新渲染作为上下文；不直接恢复一个已被后续轮次改写的共享模型线程。这避免从旧轮次分支时带入其他分支的后续对话，也不把取消的一次请求当作有效方案。SDK 原始线程 ID 仍保存在各轮记录中。SDK 的线程能力核对自 [OpenAI 官方文档](https://learn.chatgpt.com/docs/codex-sdk)及本机固定版本类型定义。

## 风格库

在已预览或已恢复的轮次上填写名称，点击“保存当前风格”。保存内容包括初始意图、后续反馈、适配与肤色思路，以及存在时的独立参考图副本；同时保留来源方案、累计参数与基线用于本地追溯。

读取另一张目标照片，选择风格并点击“适配此风格”。该操作只生成新方案，使用新照片的实际渲染和当前参数作为基线；不复制来源照片的曝光、白平衡或其他数值。检查差异后再预览新副本。参考图副本由风格库自身持有，不依赖原参考图片仍在原位置。

风格位于 `.studio/styles/<ID>/`；会话及渲染位于 `.studio/jobs/<ID>/`。两者均被 Git 忽略。没有远程发布、照片删除、向原图应用或风格删除操作。

## 命令行

```powershell
./scripts/studio.ps1 conversations
./scripts/studio.ps1 history JOB_ID
./scripts/studio.ps1 refine JOB_ID --prompt '保留曝光，只让阴影更柔和' --strength 0.65
./scripts/studio.ps1 preview NEW_JOB_ID
./scripts/studio.ps1 save-style NEW_JOB_ID --name '我的海岸'
./scripts/studio.ps1 styles
./scripts/studio.ps1 apply-style STYLE_ID --photo PHOTO_ID --strength 0.65
```

历史和风格查询、保存风格只读取本地记录，不要求 Lightroom 连接。生成、继续调整、适配和预览仍通过原 MCP 桥接读取或执行。读取/模型准备阶段可请求停止生成；副本写入和恢复阶段不提供中断。
